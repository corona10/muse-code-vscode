# Muse Code in VS Code

Muse Code is Meta's agentic coding CLI. This extension gives it a native chat UI inside VS Code, with the same layout and shortcuts you may know from the Claude Code extension.

- Muse explores your codebase, edits files, and runs commands **with your approval**.
- The chat knows your active file and selection.
- Sessions are durable: resume any past conversation from this workspace.
