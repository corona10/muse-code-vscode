# Chat with Muse

- Type a message and press **Enter** (or **Cmd/Ctrl+Enter** if you enabled `museCode.useCtrlEnterToSend`).
- Type **@** to mention a file, or press **Alt+K** in an editor to insert a reference to the current selection.
- Type **/** for commands: `/resume`, `/model`, `/mode`, `/effort`, `/compact`, `/focus`.
- Start a line with **!** to run a shell command yourself; its output joins the transcript.
- **Shift+Tab** cycles the approval mode. **Esc** interrupts a running turn.
